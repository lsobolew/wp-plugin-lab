# WordPress.org directory assets

Files here are published to the plugin directory page by `deploy-wporg.yml`. They are **not**
part of the plugin zip.

| File | Size | Purpose |
|---|---|---|
| `icon-256x256.png` | 256×256 | Icon in search results and the plugins screen |
| `icon-128x128.png` | 128×128 | Smaller icon variant |
| `banner-772x250.png` | 772×250 | Header on the plugin page |
| `banner-1544x500.png` | 1544×500 | Retina header |
| `screenshot-1.png` | any | Matches the first entry under `== Screenshots ==` in readme.txt |

Numbering matters: `screenshot-1.png` is the first line of that readme section, `screenshot-2.png`
the second, and so on.
